# Laboratory Mission 1: Welcome to the Cloud

### 🎯 Mission Overview
The initial phase of onboarding requires setting up a secure Linux environment and a version-controlled workspace. 

### 📌 Objectives
* Establish a cloud-based Linux workstation.
* Extract core hardware and system diagnostics.
* Structure local directories using terminal commands.
* Initialize a professional GitHub repository.

### 🚀 Activities Performed
1. Deployed an Ubuntu 24.04 instance.
2. Configured a new user profile with sudo privileges.
3. Audited system resources (Memory, CPU, Disk).
4. Created directory structures and Markdown files.

### 💻 Linux Commands Used
`whoami`, `pwd`, `hostname`, `cat`, `uname`, `lscpu`, `free`, `df`, `useradd`, `passwd`, `su`, `mkdir`, `cd`, `nano`

### 💡 Skills Learned
I developed a hands-on understanding of Linux user management, resource monitoring, and professional GitHub documentation using Markdown.
