
# Laboratory 09 - Mission Reflection

## My Reflection

During Laboratory Activity 9, I learned how automation makes cloud computing operations easier, faster, and more efficient. Automation is important when managing hundreds of cloud servers because performing the same tasks manually takes too much time and increases the possibility of human errors. By using Bash scripts and Cron jobs, administrators can schedule repetitive tasks such as backups and system maintenance without manually executing commands every time.

However, I also learned that automation has potential dangers. If a script contains a destructive mistake, the damage can spread quickly across multiple servers. For example, an incorrect command scheduled to run on 1,000 servers could accidentally delete important data or disrupt services. This is why scripts should be reviewed, tested, and verified before being used in actual cloud environments.

Writing a Bash script was different from creating a Docker Compose YAML file in Laboratory 6. Bash scripting focuses on executing commands and automating tasks, while Docker Compose YAML is mainly used to define and configure multiple containers. Both are useful in cloud computing, but they serve different purposes.

Looking back at Laboratories 1 to 9, my understanding of cloud computing has improved significantly. At first, I only had a basic understanding of cloud services and infrastructure. Through the activities, I gained experience with Linux commands, containers, cloud deployment, security, monitoring, and automation. I realized that cloud computing involves not only storing data online but also managing, protecting, and maintaining reliable systems.

Among the different roles, I enjoyed being a Cloud Automation Engineer the most because I learned how to make tasks run automatically using scripts. Seeing a Bash script create a compressed backup helped me understand how simple commands can solve real operational problems. Overall, this activity strengthened my technical skills and gave me more confidence in managing cloud environments.
