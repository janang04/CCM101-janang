
# Laboratory 09 - Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that can be executed automatically instead of entering commands one by one. The `#!/bin/bash` line is called a shebang, and it tells the operating system to use the Bash interpreter to run the script.

## 2. Variables

Variables are used to store information such as folder paths, filenames, and dates so they can be reused throughout a script. Using variables such as `$BACKUP_DIR` makes the script easier to update, reduces repeated typing, and helps prevent errors.

## 3. Cron Job

A cron job is a scheduled task in Linux that automatically executes a command or script at a specific time or interval. It is important in cloud operations because it allows tasks such as backups, system maintenance, and monitoring to run regularly without manual intervention.
