# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

The last laboratory on The Enterprise Cloud Architect was a good experience for me as it gave me an insight into what it means to be responsible for the management of cloud infrastructure. While completing this activity, I understood that building a successful project is not only about technical skills but also about teamwork, patience, adequate planning, and problem-solving. The latter helped me make the connection between the previous laboratories and put theoretical knowledge into practice.

One of the best parts of this experience was getting familiar with the creation of a server environment with the help of Oracle VirtualBox and Ubuntu Server. Initially, I thought that it was going to be complicated since almost all operations were carried out through command lines. Nevertheless, with the help of the further configuration, I became acquainted with various commands of the Linux system. In addition, it was great to see how easy the process of server management becomes with remote administration.

Furthermore, one of the important experiences of this laboratory was working with Docker Compose and deploying our application WordPress and MySQL database. Containerization helped us understand that different services work separately but are able to communicate with each other via network connections. Thus, we have understood the value of system architecture. Moreover, we got the experience of implementing persistent storage, which meant that information about the application was preserved even after containers restart.

Security setup became another important aspect of our project. Using UFW helped me understand the role of the firewall settings in the process of managing access to a server. I now know that security can never be overlooked, even in case of the simplest application that needs protection against unnecessary connections.

Automation was another aspect that became clear due to my work in Bash script creation and scheduling in Cron. Creating a backup of the database became an essential part of our task that involved a lot of testing and resolving of possible errors. All these tasks have taught me to examine the problem and not give up.

In general, the laboratory has increased my skills in the sphere of server management and usage of cloud technology. Most importantly, it has taught me that teamwork and continuous education are the key aspects of any success. I think that the knowledge and experience we received while creating CloudNova Enterprise Web Portal will definitely come in handy in the future.
